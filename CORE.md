# BREAKLINE: AFTERHOURS — CORE 2.0

**[Играть](https://breakline-core-zhezhe23.mixedblossom1.chatgpt.site)** · **[Контрольный бой / звук / кадры](https://breakline-core-zhezhe23.mixedblossom1.chatgpt.site/review/)**

Самостоятельная переработка CORE. Легко начать, трудно освоить в совершенстве: три основных действия, понятная музыкальная сетка, соперник с читаемыми угрозами и защитой от повторов. На Android откройте ссылку в Chrome и нажмите **ПОЙМАТЬ РИТМ**. Доступ Sites сохранён приватным владельцу: при запросе войдите в свой аккаунт ChatGPT.

## Как играть

- **РУКА / НОГА** — нажимайте непосредственно на музыкальную долю. Ближняя рамка на дорожке — точка нажатия; яркая отметка выделяет начало такта.
- **Красная треугольная отметка — УХОД.** Точный тап позволяет избежать удара и даёт усиленный контрудар. Удержание этой же кнопки служит обычным блоком и пропускает небольшой урон.
- **РРР** — апперкот, **РРН** — пробивной удар ногой, **РНРН** — разворот. Общие начала используются повторно. Ошибочное продолжение — обычный удар, без поиска другого подходящего суффикса. Нажмите карточку рецепта, чтобы закрепить подсказку; игра не вводит его за вас.
- После силового финала — одна доля выдоха. Защищаться в это время можно; уход не сокращает восстановление атаки. Успешный ритмичный уход сохраняет начатую серию, позволяя вплести защиту в комбо.
- Соперник начинает защищать ту область, которую вы повторно атакуете. Смените руку на ногу или наоборот. Силовой финал и контрудар пробивают эту защиту.
- **BREAK** — летящее колено за 40 энергии, кнопка активна при достаточной энергии. Можно потратить энергию на урон или сохранить высокий уровень музыки/эффектов.
- Клавиатура: `J` — рука, `K` — нога, `Space` — уход/удержание блока, `I` — BREAK, `Esc` — пауза.

**РАЗОГРЕВ** прощает неточность; **ДУЭЛЬ** требует читать угрозы; **МАСТЕР** добавляет более плотные серии и узкие окна. Один бой длится до 45 секунд. Победу даёт KO либо преимущество по доле здоровья; равенство без нанесённого урона не считается победой. Ранг S требует точности, защиты и разнообразных финалов. Рекорды хранятся только в браузере, отдельно по сложностям; усилений за прошлые победы нет.

## Что изменилось по сравнению с CORE 1

Переработан основной цикл, а не только оформление: единая кнопка активной/пассивной защиты, контрудары, защитный переход внутри комбо, адаптивная защита соперника, разные интервалы его атак, три сложности, рейтинг и личные рекорды. Новая оригинальная композиция **AFTERHOURS** имеет полноценный грув уже на первом уровне; энергия раскрывает ещё четыре слоя. Удачные действия добавляют музыкальные акценты, чистые all-PERFECT-комбо — отдельные перебивки. Постоянные слои и перебивки остаются разными системами.

Новая сцена ночного клуба, крупные фигуры с одеждой и объёмными силуэтами вместо тонких сегментов, читаемые намерения соперника, цвет и форма опасных отметок. Пять уровней свечения/следов, контактный hitstop, вибрация с выключателем. Все 11 сегментов скелета фиксированы, ключи проходят IK, промежуточные углы — FK с монотонными кубическими переходами и непрерывной скоростью через ключи. Кэш углов снижает повторную работу IK. Музыка продолжает играть между боями.

Синхронизация учитывает задержку аудиовыхода через `AudioContext.getOutputTimestamp()`; если метод недоступен — `baseLatency + outputLatency`. Оценка стабилизируется во время отсчёта, далее часы монотонны. В паузе доступна тонкая ручная поправка, применяемая только со следующего боя. Событие ввода оценивается по времени нажатия, а не по моменту запоздалой обработки кадра. Просроченные события не превращаются в скрытую очередь.

## Сохранность и разработка

Код — ветка **`core-rework`**, исходники `core/src/{rig,audio,rules,game}.js`, интерфейс `core/template.html`, сборка — самостоятельный `core/index.html`. Основная игра `index.html` и её GitHub Pages не изменены. CORE 1 сохранён тегом `backup/core-1.0.0`; полная игра — `backup/full-before-core-3.15.0`. Прежние проверки доступны в `tests/archive/core-1` и в резервном теге. Перенос в `main` не выполняется.

Броски, сложные парирования, «Поток», случайные вариации, остальные бойцы и полудольный эксперимент не подключены к AFTERHOURS; их код полной игры сохранён. Чужая музыка, голоса или толпа не используются. Все инструменты и звуки синтезируются локально оригинальным кодом; сетевых аудиозависимостей нет.

```sh
npm ci --ignore-scripts
npx playwright install chromium
npm run build:core
npm run test:core
npm run render:core # ffmpeg: полный контрольный бой, звук, замедление и таблица поз
```

`CHROMIUM_PATH` выбирает системный браузер. CI проверяет `core`/`core-rework`, не публикует GitHub Pages. Подробный контракт и критерии приёмки — [AFTERHOURS.md](AFTERHOURS.md).

Проверено в Chromium с настоящим Web Audio и сенсорным вводом. Реальный Android и его звуковой тракт в этой среде не тестировались. Автотесты показывают разницу стратегий и корректность механики; субъективную увлекательность они не доказывают. Это завершённый стилизованный бой на фиксированной дистанции, без симуляции сложной контактной физики.
