# BREAKLINE CORE 1.0.0

Самостоятельный игровой прототип: короткий бой кикбоксёра с RIVAL, музыка, ритм, три комбо и немедленный реванш. Исходники находятся **только в ветке `core`**. Основная игра не заменена.

## Запуск

Откройте **[BREAKLINE CORE](https://breakline-core-zhezhe23.mixedblossom1.chatgpt.site)** в Chrome на Android. Публикация подтверждена 11.11.2026 через Sites; доступ сохранён приватным для владельца. Если Sites запросит вход, используйте тот же аккаунт ChatGPT. Нажмите **НАЧАТЬ БОЙ**, разрешая запуск звука жестом; сначала звучит четыре доли отсчёта. При реванше музыка продолжается, отсчёт — две доли. Смена вкладки ставит бой и аудиочасы на паузу; возвращение требует «Продолжить».

Локальный вариант: скачайте **`core/index.html` из ветки `core`**, откройте в браузере. В нём все стили, код и звуки; внешние файлы/URL не нужны. Android-файловые менеджеры иногда показывают HTML своим просмотрщиком: тогда используйте размещённую версию в Chrome.

Полная игра остаётся по адресу https://zhezhe23.github.io/Breakline/?v=3.15.0.
Резервный аннотированный тег **`backup/full-before-core-3.15.0`** указывает на `f3f33efbf0f045e399056acf8c838a29aec1cc47`, сохранён на GitHub до разработки. Корневой `index.html` байт-в-байт прежний. В `main` изменений CORE нет, Pages workflow не изменён.

## Правила

- 120 BPM, одна четверть — 500 мс. Нажатие **на долю**, не за полдоли. PERFECT: ±65 мс, GOOD: ±125 мс, OFF: дальше. OFF даёт движение без урона и прерывает серию.
- РУКА (`J`), НОГА (`K`). Три рецепта: **РРР** — силовой апперкот; **РРН** — пробивной удар ногой; **РНРН** — удар с разворота. На экране всегда видны рецепты и допустимые префиксы.
- Префиксы дерева переиспользуют одну хореографию: Р — джеб, РР — кросс, РН — удар в корпус ногой, РНР — хук. Ветвление только по принятому вводу. Ошибочное продолжение расходуется на обычный удар, без поиска суффикса. Новый рецепт возможен со следующего принятого действия. Тайм-аут префикса — 1250 мс.
- Обычное восстановление — 390 мс, силовое — 675 мс: **после финала/спецприёма пропустите следующую долю**. Хвост анимации продолжается независимо от готовности. Одно раннее нажатие в пределах 80 мс можно сохранить в буфере: исходное время и оценка не меняются; просрочка больше 110 мс отклоняется. Буфер не разрешает отменять восстановление.
- БЛОК — удерживать (`Space`), действует после восстановления, снижает урон до 3. УКЛОН (`L`) — 300 мс, защита с 20-й до 245-й мс, повтор через 1000 мс. Спецприём **ПУЛЬС-КОЛЕНО** (`I`) — летящее колено, 30 энергии, 30 урона при PERFECT.
- Соперник предупреждает об атаке за 320 мс и атакует каждые 4 доли, со смещением в полдоли. Блок можно удержать заранее. Силовое попадание может сорвать подготовку; обычные удары не блокируют ИИ навсегда. Реакции/оглушение конечны: 105/190 мс. Гарантированного combo hitstun в CORE нет.
- Здоровье 180/340, бой 60 секунд. При тайм-ауте сравнивается доля оставшегося здоровья. Урон: рука 8, нога 10, финал 26, спецприём 30; GOOD ×0,8. Одно действие — один контакт. Силовое попадание фиксирует обоих бойцов на 85 мс **только визуально**, музыка/обработка боя не останавливаются. KO показывается после короткого завершения, затем доступен реванш.

## Энергия и оригинальная музыка

Энергия 0–100; уровни 1/2/3/4/5 на порогах 0/20/40/60/80. PERFECT +5, GOOD +2, чистый финал +12, получение урона −9, OFF −4; после 2,2 с без прироста начинается медленное снижение. Расход спецприёма тоже может понижать уровень.

Визуально: база → лёгкое свечение → следы ударов → усиленная аура/яркие глаза → максимальная аура и частицы. Максимум 40 частиц и 14 точек следа, DPR ограничен 2, тяжёлых полноэкранных фильтров нет. `prefers-reduced-motion` отключает вспышку, тряску и дополнительные следы.

**CORE CIRCUIT** — новая процедурная композиция 120 BPM, гармония Am–F–C–G, без чужих записей, голосов или толпы. Пять независимых слоёв: основная ритм-секция/бас/мотив; перкуссия; гармония; контрмелодия; кульминационная верхняя партия. Смена уровня применяется на следующей четверти после горизонта планировщика, плавность 240 мс. Фраза не перезапускается. Mute меняет общий gain, не транспорт.

Перебивка — другая система: только после **всех подтверждённых PERFECT-попаданий** законченного рецепта. Четыре шестнадцатых ударно-мелодического ответа с ближайшей восьмой, согласованные с текущим аккордом. Повторный ID/неверная серия отклоняются, между ответами минимум две доли. Ни перебивка, ни hitstop не меняют музыкальную сетку или постоянный уровень аранжировки.

## Устройство и сохранённые механики

`core/src/rig.js`: неизменяемые 11 сегментов, трёхзвенный корпус, ограничения суставов; математика IK/FK из стабильной 3.14.0 (`5dc1ff2`). IK ставит ключевые позы, между ними смешиваются ограниченные FK-углы: кисть не проходит через плечо с резким разворотом локтя. Контакт, продолжение движения, сбор конечности и связующий выход заданы отдельно. Незавершённый чистый префикс удерживает переходную позу вместо обязательного возврата в нейтраль. Новое разрешённое действие начинается из текущей позы.

`core/src/audio.js`: оригинальные инструменты, микс, независимые слои/перебивки; единый `AudioContext.currentTime`. `core/src/game.js`: отдельные правила CORE, дерево трёх рецептов, фиксированные задержки контакта 85–150 мс, урон/восстановление/конечные реакции, Canvas и сенсорный UI. Экспериментальная полудольная модель не импортируется.

В CORE временно не подключены: остальные бойцы, броски/освобождения, сложные парирования, «Поток», случайные вариации одиночных ударов и архивная лаборатория, дополнительные рецепты/спецприёмы, прыжок/присед/джойстик перемещения, выбор трека/арены. Они остаются в полной игре и её исходниках. Голосовых подмен/синтетической толпы нет.

## Проверки и воспроизведение

```sh
npm ci --ignore-scripts
npx playwright install chromium
npm run build:core
npm run test:core
npm run render:core # дополнительно нужен ffmpeg
```

`CHROMIUM_PATH` позволяет выбрать браузер. В облачном Linux для запуска Chromium могут требоваться разрешения среды. CI `verify-core.yml` проверяет только ветку CORE и **не публикует GitHub Pages**.

- Проверки правил: окна ритма, три рецепта/общие префиксы/ошибки/тайм-ауты, буфер без повышения точности, восстановление, один контакт, блок/уклон/спецприём, конечный стан/повторные атаки ИИ, пять уровней, победа/реванш, неизменность полной игры.
- 6160 промежуточных скелетов, 67 760 измерений сегментов; контроль ограничений, угловых скачков, перемещений суставов, опоры, фаз ударов, follow-through и непрерывности начала следующего действия. Летящее колено намеренно отрывается от пола.
- Chromium с реальным AudioContext и native touch: три комбо, спецприём, удержание/отпускание блока, уклон, pause/resume, mute без остановки транспорта, пять аудиослоёв и затухание до первого. OfflineAudioContext рендерит 16 с музыки с ростом/падением уровня и отдельной перебивкой; проверяются слышимый сигнал и запас по пику.
- Шесть размеров: 320×568, 360×640, 390×844, 412×915, 740×360, 844×390. Размеры кнопок ≥44 px, отсутствие наложений, аудит реально отрисованных скелетов, отсутствие ошибок браузера/внешних запросов.
- `test-artifacts/core` содержит JSON-отчёты, мобильные скриншоты, таблицу семи фаз восьми техник, видео 1×/0,5× **без звука**, WAV музыкального развития. Тестовый доступ внедряется только в копию в памяти; в релизе его нет.

Визуальная оценка скриншотов и промежуточных поз выполнена в Chromium. Это стилизованный прототип с фиксированной дистанцией, а не физическая симуляция. На настоящем Android и мобильном аудиотракте ещё нужно оценить ощущение ритма, удобство блока/уклона, читаемость финишеров и баланс громкости/слоёв. Автотесты не доказывают субъективную увлекательность или производительность конкретного телефона.

Контрольные материалы сохранены в `core/review/`: откройте `index.html` рядом с видео/MP3/таблицей фаз. Полный автоматический бой с активным ИИ также проверен: победа, восемь комбо, достижение уровня 5; соперник наносит урон и не находится в бесконечном стане. Финальные результаты: 93 050 утверждений правил/анатомии и 141 браузерная проверка; максимальная относительная ошибка длины 7,78×10⁻¹⁶, пик аудиорендера 0,555 без клиппинга. Общая большая регрессия полной игры повторно не запускалась: её исходник неизменен, проверены синтаксис и SHA-256.
