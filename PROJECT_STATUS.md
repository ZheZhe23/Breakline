## Ограничения и границы

Последняя инструкция пользователя требует согласования публикации: текущий цикл **не развёртывает** изменения на живом сайте. Готовый кандидат будет сохранён в отдельной ветке с воспроизводимой сборкой. GitHub push явно разрешён. Нет новых расходов, внешних аудиоресурсов, голосовых лицензий или юридически значимых действий.

Реальное устройство Android недоступно; браузерные проверки мобильных размеров нельзя называть проверкой Android. Численная анатомия относится к архивному rig, а рисованные кадры проверяются визуально. Видимая кадровая анимация не обеспечивает математическую непрерывность положения каждого сустава.

## Среда и воспроизведение

Node 24, Playwright 1.62.1, Chromium `/usr/bin/chromium`, системный ffmpeg; исходники/артефакты в `/workspace/Breakline`. Локально Playwright предоставлен через NODE_PATH, а не node_modules проекта. Для видеозаписи установлен совместимый бесплатный компонент `ffmpeg-1011` в `/workspace/.cache/ms-playwright`; запуск: `PLAYWRIGHT_BROWSERS_PATH=/workspace/.cache/ms-playwright node tests/core-live-bout.cjs`. В свежем окружении: `npm ci --ignore-scripts`, затем `npx playwright install --with-deps chromium`; CI использует закреплённую версию из package-lock. Не применять неприкреплённый npx до npm ci: он может выбрать другую версию CLI.

Команды текущего цикла: `npm run build:core`, `npm run check`, `npm run check:core`, `node tests/core-rules.cjs`, `node tests/core-browser.cjs`, `node tests/core-live-bout.cjs`, `node tests/render-core.cjs`, `git diff --check`. Статус последнего финального прогона дописывается ниже после завершения.

Выявлены и устранены ошибки сценариев проверки: ранняя проверка результата до нового контакта 230 мс; неверная горизонтальная регистрация нового рисунка (исправлена в коде упаковки, не спрятана тестом); отсутствие ffmpeg Playwright при первой записи; чтение состояния ИИ слишком рано; чтение флага паузы раньше окончания асинхронного AudioContext.resume. Новые проверки ожидают фактические события, не изменяют оценки/урон и не ослабляют условия победы.
